04 · Permissions & graph

RBAC grants resolve hote hain, phir typed graph banta hai

Effective-permission resolver

  • Role aur ClusterRole bindings se inherited rules jodta hai.
  • Group membership, wildcards aur namespace scope samajhta hai.
  • Har derived action ke saath granting binding/role ka evidence rakhta hai.

Graph Builder

  • Nodes: ServiceAccount, Role, Binding, Workload, Secret, Namespace, User/Group.
  • Structural edges: BOUND_TO, GRANTS, RUNS_AS, LOCATED_IN.
  • Action edges: CREATE_POD_AS, REQUEST_TOKEN, IMPERSONATE, CAN_BIND, EXEC_INTO, etc.
  • Sinks: cluster-admin aur node-access.

Implementation: NetworkX MultiDiGraph · har action edge ke saath authorization evidence.

07 · Risk & confidence

Severity batati hai impact; confidence batata hai evidence level

Risk score

Sink impact × path-length factor × sabse mushkil hop ki exploitability; direct-grant paths ko chhota bonus.

0–100 → LOW / MEDIUM / HIGH / CRITICAL

Short, easier path zyada risk score le sakta hai. Exact score path details ke saath report hota hai.

Confidence lifecycle

POSSIBLE → LIKELY → REACHABLE → OBSERVED → CONFIRMED

Graph path reachability dikhata hai. Matching audit event runtime request ka evidence deta hai. CONFIRMED lab validation status hai.

13 · Safety, limits & future

Security analyst ko decision support; proof ki boundaries clear

Safety by design

  • Real cluster par passive, read-only observer.
  • Secret values read/dump nahi karta.
  • Safe event simulation local lab-only.

Limitations

  • Snapshot TOCTOU: scan ke baad state badal sakti hai.
  • OBSERVED correlation ke liye audit logs zaroori.
  • Admission policy effects fully simulate nahi hote.
  • Secret contents nahi dekhne se kuch credential links uncertain.

Practical use

RBAC review, attack-path triage, lab teaching aur remediation verification ke liye findings ko human review ke saath use karein.

Future extensions

Kyverno/OPA awareness, Falco/eBPF signals, continuous monitoring, SIEM integrations aur cloud identity (IRSA → IAM) paths.
